# Notes

## Construction

1. Print all parts of Rain Gauge MAKE SURE TO USE "LINES" OR SIMILAR INFILL PATTERN FOR TOP AND BOTTOM GRID PRINTS AND SET TOP AND BOTTOM WALLS TO 0. There should be no top or bottom walls to these parts as they are supposed to let water through while blocking wasp and other insects from making nest inside the rain gauge. see fig. 1.
2. Drill, file, and sand parts to ensure good fittment between prints.
3. Install 2 ball bearings into EchoWeather_bucket.
4. Cut 4mm to length to span bucket and fulcrum parts.
5. Use washers to act as spacers and to reduce frictiion between fulcrum and bucket
6. Install magnet in bucket WITH SOUTH POLE FACING OUTWARDS.

## Components

* 2x5mm round magnet
* (2) 8x4x3 ball bearings
* 4mm steel rod
* Assembled support rod (see support rod notes)

## Specs

This setup was calculated from test to be about 0.7mm (0.028in) for each tip of the bucket.
This module is not very sensitive to rain, and will probably be re-designed in the future. 
With a 5-min measuring interval, this module can only measure rain rates greater than 0.33 in/hr.
