# Project Goals

- [x] Design, build, and program a small weather station using a variety of sensors.
- [x] Construct station using 3D printable prints and cheap, commercially available parts.
- [x] Design a smart phone app to display current weather variables.
- [ ] Build and deploy multiple stations across wide geographic area.
- [ ] Build and train AI model using collect weather data for future weather predictions.
- [ ] Update smart phone app to include predicted forecast.
